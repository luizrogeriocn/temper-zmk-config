# Temper ZMK Config

This is my personal ZMK config for the [temper](https://github.com/raeedcho/temper).

Some notes about this config:
- Five layers are defined: a Colemak-DHm default layer, a QWERTY base layer, a num/nav layer, a function layer, and a game layer
- Both base layers use [urob's timerless homerow mods](https://github.com/urob/zmk-config#timeless-homerow-mods)
- The num/nav layer puts navigation on the left hand and a numpad on the right hand
- The function layer has media, Bluetooth, and function keys, and is used to switch between the default and QWERTY base layers
- The game layer provides a simpler gaming layout and can jump back to the default layer
- The default and QWERTY layers share the same combos
